# 物理模型与时间箱规则

## 1. 传播时间与光程

每条相机路径在每个反弹段独立维护三个量（`tracer.py`）：

| 量 | 定义 | 单位 |
|---|---|---|
| 几何长度 `geom_length` | 各段欧氏长度之和 | m |
| 光程 `opl` | `Σ 段长 × 段内 IOR` | m |
| 传播时间 `flight_time` | `Σ 段长 / (c / IOR) = OPL / c` | ns |

到达时刻 = 光源脉冲时刻 + 传播时间。介质（电介质盒）边界在路径追踪时按
Fresnel 反射/折射处理，阴影段（NEE）用 `_box_intervals` 解析积分穿过的
介质区间，因此**多个反弹的延迟来自逐段求和，而非相机到命中点的直线距离**。

真空 `c = 0.299792458 m/ns`，介质速度 `c/IOR`，这些常量在每个渲染结果的
`units` 字段中显式给出。

## 2. 时间分箱核与边界规则

箱 k 覆盖半开区间：

```
[t0 + k·dt, t0 + (k+1)·dt)
```

恰落在边界 `t0+k·dt` 的到达时刻归入箱 k（左闭右开，`floor((t-t0)/dt)`）。
边界判定带 1e-9 个箱宽的相对容差，使 `0.3/0.1 = 2.999…` 这类十进制精确边界
不会因二进制误差落到前一个箱。支持三种核（`kernel.py`）：

- **point**：Dirac 点沉积，进入包含该时刻的单个箱。
- **box**：在 `[t-w/2, t+w/2]` 均匀分布，按解析面积分裂到所有相交箱；
  脉冲恰落在两门交界且宽度已知时，两门各得 50%（见 `tests/test_two_gate.py`）。
- **gaussian**：标准差 w，在 ±4w 处截断并对保留质量重归一化，保证总能量守恒，
  截断尾部比例由核函数报告。

高斯核的截断重归一化与盒形的解析分裂保证：**同一条路径的权重在箱上积分恰好等于
其原始权重**，不重复分配，也不漏掉。超出**记录区间** `[t_min, t_end)` 的能量
单独计入 `energy_lost_edge` 并在界面显示，绝不会被折回最末一个箱。

### 记录区间与改时间原点

记录区间的右端**精确等于**请求的 `t_max`（`t_end = t_max`），而非由
`n_bins·dt` 反推：`n_bins = ceil((t_max-t_min)/dt)`，当区间不是 `dt` 的整数倍时
最末一箱更窄。这样把右端缩短少许会立即改变 `t_end`，本应被裁去的回波随之记为
边缘损失；而不会因为 `round()` 把箱数取整、边缘悄悄外扩而把范围外的一次反射
挪回最后一格。移动 `t_min` 亦然（旧实现的 `round()` 会让边缘随原点漂移）。

**可逆的重分箱**：沉积始终以精确到达时刻 `PathRecord.arrival_ns` 为输入
（`render.rebin_at_origin` 用同一批记录在新原点上重新沉积），因此把原点平移半箱
再平移回来，到达表、箱内能量与显示峰质心都逐位复原。绝不把**已积分**的箱能量
整体搬移或按均匀假设细分边缘箱——那会虚构亚箱顺序且不可逆。两种候选实现的对照
与取舍（精确到达重分箱 vs 整箱细分）见 `tests/test_origin_remap.py`。

## 3. 稳态相容性

瞬态图像在所有时间箱上的积分等于同模型的稳态结果。测试
`tests/test_physics.py::test_conservation` 断言：

- 时间箱能量总和 = 追踪总能量（相对误差 < 1e-3）；
- 完整时间窗下边缘损失 < 1%；
- 稳态图（每采样归一化）= 瞬态积分 / 采样数。

## 4. 曝光门与读出端决策

门积分只对落入 `[start, end)` 的箱求和。决策逻辑（`render.py::readout_decision`）：

1. **门外泄漏**：两门之外能量超过 10% 时提示加宽门或重追踪更宽窗口。
2. **两路可分辨性**：若任一路在两门中的能量都超过该路总量的 25%，说明到达
   没有被定位到单门，报告不可分辨。
3. **已知探头宽度 ≥ 箱宽**：允许按核把能量分到两门，但只能报告分布，不能
   声称单一到达瞬间。
4. **历史粗箱**：只存整箱总量时，缩窄门无法恢复亚箱顺序，决策强制为
   `retrace`，并给出当前可分辨半宽 `±max(dt, 核宽, 粗箱宽)/2`。

## 5. 双门实验（two_gate）

- 真空路 L_A：轴向几何距离 = 光程 = 2.75 m。
- 慢速路 L_B：几何 2.0 m，其中 1.5 m 在 IOR=1.5 的介质板内，
  光程 = 0.5×1 + 1.5×1.5 = 2.75 m。
- 两路到屏幕的传播时间都是 `2.75/c = 9.1730 ns`，相机腿对两路相同，
  因此相机端同刻到达。该数值可由 `segment_metrics` 与独立几何计算双向复算
  （`tests/test_two_gate.py`、`tests/test_physics.py`）。

## 6. 明确不做的事

- 不把普通渲染图按距离淡入当作光传播：每个切片都来自真实路径的到达时间分箱。
- 不以“动画看起来有波前”作为证据：所有峰位都能用 OPL/c 独立复算。
- 不从历史整箱总量中虚构亚箱顺序；不把已积分的箱能量整体搬移来“改原点”。
- 不把记录区间外的回波折回边缘箱：它们是边缘损失，不是末箱的新增能量。
