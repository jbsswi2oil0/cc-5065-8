# 使用指南 · 瞬态光传输渲染器

## 图形入口（主要方式）

启动本地实验窗口：

```bash
python3 -I run_server.py            # 默认 http://127.0.0.1:8000/
python3 -I run_server.py --port 8123
```

浏览器打开 `http://127.0.0.1:<端口>/`，这是**瞬态渲染的图形入口**。页面上的
“运行瞬态渲染”按钮会调用后端真实的蒙特卡洛瞬态路径追踪
（`transient_renderer.render.render`），返回的瞬态切片、像素时间响应与光程分布
均为实时计算结果，没有任何固定或预烘焙数据冒充。

### 界面能做什么

- **光照实验参数**：场景（4 个预设）、每像素采样数、最大反弹、分辨率、时间窗、
  时间沉积核（点 / 盒形 / 高斯）与探头响应宽度、历史粗箱模式。
- **瞬态切片**：时间滑条或“播放波前”逐箱查看能量到达；左侧小图为同模型的
  稳态参考（时间积分）。点击切片任意像素查看该像素的时间响应与 OPL 分布。
- **可移动曝光门**：两个门共享一个可拖动交界；修改后点“应用门并重新读出”，
  后端复用已追踪光路，只重新做时间箱积分（`/api/regate`），不重新追踪。
- **读出端分析**：显示两门能量、每路能量、门外泄漏、可分辨半宽，以及
  “可分辨 / 需重新追踪 / 只能给范围”的决策与依据。
- **历史粗箱**：勾选后只保留整箱总量，界面明确提示亚箱到达顺序无法恢复，
  缩窄门也不会凭空生成箱内顺序，必须重新追踪。
- **改时间原点 / 可逆重分箱**：`render.rebin_at_origin(result, t_min, t_max)`
  用同一批精确到达时刻在新原点上重新沉积。把原点平移半箱再平移回来，到达表、
  箱内能量与显示峰质心逐位复原；缩短 `t_max` 使记录区间右端立即收缩，范围外的
  回波计入边缘损失而非末箱。库函数不在界面按钮中暴露，供脚本与回归测试使用。

## 命令行（仅辅助）

CLI 用于批处理与自检，不是主要入口：

```bash
python3 -I transient_renderer/cli.py render --scene two_gate --samples 16
python3 -I transient_renderer/cli.py render --scene path_lengths \
        --kernel gaussian --width 0.3 --gate 25,33 --gate 33,45
python3 -I transient_renderer/cli.py test-self
```

## 单位与约定

- 长度：米（m）；时间：纳秒（ns）。
- 真空光速 `c = 0.299792458 m/ns`；介质内速度 `c / IOR`。
- 每条路径逐段累计几何长度、光程长度 `OPL = Σ length·IOR`、
  传播时间 `t = Σ length / (c/IOR) = OPL/c`，多反弹不使用端点直线距离估算。
